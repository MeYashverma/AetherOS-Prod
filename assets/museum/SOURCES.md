# Included public-domain artworks

These are real reproductions included to make Museum useful without external API
access. They are explicitly labelled as an included collection, **not** current
museum search results. No generated art is used. Files were converted to WebP,
without creative edits or enlargement. They are browsing-size reproductions, not
archival/high-resolution downloads.

Metadata was checked against the Art Institute of Chicago API for each record;
all three returned `is_public_domain: true`. API metadata (except descriptions)
is designated CC0 by the museum. These faithful reproductions depict public-domain
two-dimensional works; the linked pages document their provenance. The local
image delivery does not depend on these external links remaining available.
